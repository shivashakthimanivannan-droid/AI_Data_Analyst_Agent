AI Data Analyst Agent

An AI-powered multi-agent business analytics application developed using Python, Streamlit, LangGraph, Google Gemini, Pandas, and SQLite.

Project Features

File Analysis Agent

Performs analytical calculations on uploaded datasets using Pandas.

Database Agent

Analyzes structured business records using SQLite queries.

Web Research Agent

Retrieves external information using web and news search tools.

Data Cleaning Studio

Supports human-approved cleaning, validation and audit logging.

Multi-Agent Architecture

User Question → LangGraph Supervisor → Specialized Agent → Analytical Result

Technology Stack

Python | Streamlit | Pandas | Plotly | LangGraph | Google Gemini | SQLite | DDGS
